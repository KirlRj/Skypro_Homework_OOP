# Проект "Обучение SkyPro". Введение в ООП

## Описание:

Проект "Обучение SkyPro" это выполнение домашнего задания по курсу "Python разработчик". В данном проекту будет рассматриваться введение в ООП.

1) Первой домашней работой было создание двух классов "Category" и "Product". Находятся они в файлах category.py и product.py соответственно.
Структура Category - имя продукта, описание продукта, входящий список продуктов в данную категорию.
Структура Product - имя продукта, описание продукта, цена продукта, количество
2) Добавлен функционал для новых категорий продуктов: Смартфоны и Газонокосилки. Добавлено ограничение, которое не позволяет выполнять складывание товаров разных категорий.

## Тестирование:

Для тестирования использовался фреймворк pytest.
Если у вас его нет, то скопируйте команду для установки.
```
poetry add --group dev pytest
```
Для проверки покрытия тестами, использовалась библиотека pytest-cov.
Если ее нет, то скопируйте команду для установки.
```
poetry add --group dev pytest-cov
```
Для проверки покрытия тестами используйте команду.
```
poetry run pytest --cov
```
Для формирования отчета об покрытии тестами в формате HTML, используйте команду.
```
pytest --cov=src --cov-report=html
```
где src - пакет с модулями, которые тестируются.
Отчет будет находиться в htmlcov/index.html
